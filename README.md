# 小説投稿サイト

ログインユーザーは小説を作成、投稿を行い作品を共有しあう場です。
各話ごとに高評価機能がありランキングで競い合うなど、モチベーション機能もあります。
レスポンシブ機能もあり媒体ごとに使いやすいように意識しました。

* Ruby 4.0.6
  
* Ruby on Rails 7.2.2.1
